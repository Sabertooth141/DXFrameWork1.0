==============================================================================
  DRAGON HUNT DEMO
  自作の DirectX 11 エンジン「DXFramework」で作っているボスバトルです
==============================================================================

------------------------------------------------------------------------------
 1. コンセプト
------------------------------------------------------------------------------

SF風のドラゴンと1対1で戦う、モンスターハンターのようなボスバトルです。

自分が好きなのは「派手な技で格好よく倒す」より「敵の動きを観察して、
少しずつ攻略していく」タイプのゲームです。なので、このドラゴンも手加減せずに
しっかり反撃してきますし、プレイヤーが左右や背後に回り込めばそれに合わせて
動きを変えます。

ただ、理不尽な強さにはしたくありませんでした。ドラゴンの行動はランダムでは
なく、距離や向き、クールダウンなどのルールで決まっています。何度か戦えば
「この位置にいるとこの技が来る」と読めるようになり、上達するほど自分で
戦いをコントロールできている感覚が持てる、というのが目標です。

体力が半分を切ると、ドラゴンは必ず空中から大技を仕掛けてきます。着地して
咆哮したら第2フェーズの合図で、そこからは動きが一段階速くなります。


------------------------------------------------------------------------------
 2. 操作方法
------------------------------------------------------------------------------

 移動
   W / A / S / D ........ 移動（カメラの向き基準）
   Shift（長押し）....... ダッシュ
   Space ................ 前転回避（タイミングが合えば攻撃をすり抜けられます）

 攻撃
   左クリック ........... コンボA（最大4段）
   右クリック ........... コンボB（最大4段）
   ※攻撃中にタイミングよくもう一度押すと、次の段につながります

 カメラ
   マウス移動 ........... カメラを回す
   マウスホイール ....... ズーム
   Q .................... ドラゴンの方へカメラを向ける
   Alt（長押し）......... マウスカーソルを表示する

 デバッグ用（Debug ビルドのみ）
   F1 ................... エディタの表示／非表示
   F2 ................... 当たり判定の表示
   F5 ................... ドラゴンに100ダメージ（大技をすぐ見たいとき用）


------------------------------------------------------------------------------
 3. 実装したシステム
------------------------------------------------------------------------------

 【スケルタルアニメーション】
   アニメーションの特定のタイミングに「ここで攻撃判定が出る」「ここから
   次のコンボを受け付ける」といったイベントを置けるようにしました。攻撃や回避
   の踏み込みはアニメーション側の移動（ルートモーション）をそのまま使っています。

 【当たり判定】
   攻撃判定と食らい判定は、骨にくっつけたカプセルで作っています。そのため、
   尻尾を振れば尻尾の判定がちゃんと一緒に動きます。判定は「尻尾」「ブレス」の
   ようにグループごとにアニメーションイベントで出し入れします。1回の攻撃で
   何度も当たらないようにしつつ、ブレスのような技だけは多段ヒットするように
   しています。

 【移動の共通化】
   プレイヤーとドラゴンは同じ移動の仕組みを使っています。違うのは「どう動き
   たいか」を決める部分だけで、プレイヤーはキー入力、ドラゴンはAIがそれを
   決めます。こうしておくと、移動まわりの修正が両方に一度で効くので楽です。

 【HP】
   これも両者で共通です。攻撃ごとにダメージ量と「怯ませる力」を別々に持たせて
   います。HPが50%を切った瞬間に一度だけ通知が飛ぶようになっていて、大技が
   始まるまではそれ以上HPが減らないようにしてあります。これで、一気に削り
   切って大技を見ないまま終わる、ということが起きません。

 【ドラゴンのAI】
   このゲームの一番の見どころです。目標は「ちゃんと強いのに、理不尽ではない
   敵」。プレイヤーの動きにはしっかり反応しつつ、行動はすべて読めるように
   する、という二つを両立させるために、以下の仕組みを作りました。
 
   ・まわりの見方
     毎フレーム、プレイヤーとの距離と方向を「近い／中くらい／遠い」
     「前／左／右／後ろ」に分けて把握しています。境界線ぎりぎりで判断が
     ブレないように、少し余裕を持たせています。
 
   ・戦闘の始まり
     最初はおとなしくしていて、プレイヤーが近づくか攻撃すると振り向いて
     咆哮し、そこから戦闘が始まります。
 
   ・振り向き
     プレイヤーが横や後ろにいると、90度か180度の旋回モーションで向き直り
     ます。ただ今いる位置ではなく「少し先にプレイヤーがいそうな場所」を
     狙うので、回り込み続けるだけでは逃げ切れません。
 
   ・攻撃の選び方
     5種類の攻撃の中から、今の距離と方向で使えて、クールダウンが終わって
     いるものを選び、その中で一番優先度の高い技を出します。ランダム要素は
     ありません。攻撃は出始めだけプレイヤーを追いかけ、途中から向きが固定
     されるので、ちゃんと見ていれば避けられます。
 
   ・攻撃後のスキ
     どの攻撃にも硬直があり、空振りしたときはさらに長くなります。ここが
     プレイヤーの攻めどころです。
 
   ・半分HPの大技と第2フェーズ
     飛び上がって距離をとり、狙いを定めてからブレスを吐きながら一直線に
     突っ込んできます。着地後の咆哮のあとは動きが速くなり、スキも短く
     なります。HPが50%を切っても、攻撃の途中で割り込むことはせず、今の行動が
     一区切りついたところで始まります。
 
   ・デバッグ画面
     今の状態や、各攻撃が「なぜ今使えないのか」を画面上で確認できるように
     しました。調整するときにかなり役立っています。
 
   土台はシンプルなステートマシン（13状態）です。状態の切り替えはフレームの
   最後にまとめて行い、死亡やフェーズ移行のような「どの状態からでも起きる
   遷移」は1か所で判定するようにして、状態が増えても見通しが悪くならない
   ようにしています。

 【プレイヤーのアクション】
   攻撃のつながりはデータで定義していて、2種類の4段コンボがあります。
   攻撃中のボタン入力は少しの間だけ覚えておくので、多少早く押しても次の段に
   つながります。回避の無敵時間もアニメーションのタイミングで決めています。
   被弾すると、モンハンのように攻撃された方向へ吹っ飛ばされてダウンし、
   起き上がるまで少し時間がかかります。

 【カメラ】
   プレイヤーの肩越しに追いかけるカメラです。ロックオンはあえて入れず、
   代わりにボタン1つでドラゴンの方を向けるようにしました。

 【キャラクター設定のデータ化とエディタ】
   当たり判定やアニメーションのイベント、ブレンドの時間などは、コードでは
   なく JSON ファイルで管理しています。エンジン内のエディタから実行中に
   直接いじって保存できるので、調整のたびにビルドし直す必要がありません。

 【仮のエフェクト】
   本番のエフェクトはまだありませんが、攻撃判定が出ている間はその部分が
   光るようにしてあります。どこが危ないか、見て分かるようにするためです。
